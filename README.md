# Password Strength Analyzer and Cracking Simulation Tool

## Overview

This project analyzes password strength using multiple security checks
and simulates possible password cracking attacks.

## Features

- Password Strength Analysis
- Password Score
- Entropy Calculation
- Effective Entropy
- Dictionary Word Detection
- Keyboard Pattern Detection
- Sequential Number Detection
- Repeated Character Detection
- Password Statistics
- Attack Prediction
- Crack Time Estimation
- Password Recommendations
- CSV Dataset Analysis
- Streamlit Dashboard

## Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
